## </> About

**DaBoyz Bot** is a custom Discord bot created for the DaBoyz discord community.

The bot is designed to provide useful utilities and community-focused functionality while remaining lightweight and straightforward to maintain.

This bot will grow over time as new features are introduced.

## </> Requirements

To run your own instance of the bot, you will need:
- A Discord account
- Bot created via Discord Developer Portal
- Bot Token
- .NET/C# Enviroment

The exact requirements may change as the project grows.

## </> Getting Started

### 1. Clone the repository

``` 
git clone https://github.com/KaroDevGroup/KDGBot.git
cd KDGBot.git
```

### 2. Configure the bot

Create/configure your Discord application through the Discord Developer Portal.

You will need to provide the bot with the permissions required by the commands and functionality you intend to use.

### 3. Build the project

From the project directory:
```
dotnet build
```

### 4. Run the bot
```
dotnet run
```

Once the bot successfully connects to Discord, it should appear online in the servers where it has been installed.

## </> Privacy 

DaBoyz Bot is designed to minimize the amount of information it collects and stores. 

Depending upon the command being used and the permissions granted to the bot, Discord may provide information such as:
- Discord User ID
- Username/display name
- Server/Guild information
- Role information
- Voice channel information
- Voice state information
- Interaction/command information

The bot does **not intentionally** record or store voice conversations simply because it joins a voice channel.

For complete information about data handling, collection, and retention, see the project's **Privacy Policy.**
